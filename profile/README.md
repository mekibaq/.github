# mekiba

**The Quantum Toolkit for Web3.** mekiba checks how exposed a wallet is to a future quantum computer and lets you try post-quantum cryptography in your browser.

- Website: [mekiba.si](https://mekiba.si)
- Terminal: [mekiba.si/terminal](https://mekiba.si/terminal/) (Quantum Scan and Key Lab are live)
- Docs: [mekiba.si/docs](https://mekiba.si/docs/)
- X: [@mekibaq](https://x.com/mekibaq) · Telegram: [t.me/mekibaq](https://t.me/mekibaq)

## Open repositories

| Repository | What it is |
|---|---|
| [quantum-scan](https://github.com/mekibaq/quantum-scan) | The rules Quantum Scan uses to tell whether an address's public key is already on chain (EVM, Bitcoin, Solana) |
| [check-phrase](https://github.com/mekibaq/check-phrase) | Four words that name an address, so you can compare two addresses at a glance. Spec, code and test vectors |
| [brand](https://github.com/mekibaq/brand) | Logo files and color and font tokens, with the rules for using them |

The website, the access server and the Telegram bot are not public.

## Safety

- mekiba never asks for a seed phrase, a private key, a transaction or a token approval. Anyone who does is not mekiba.
- Admins never DM first.
- No quantum computer today can break the signatures that protect wallets (secp256k1, Ed25519). The risk is about the future, and mekiba describes it that way.
- Report a security problem to [contact@mekiba.si](mailto:contact@mekiba.si).
